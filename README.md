# 公众号写作助手

一个 Electron 桌面端的公众号创作工作台：把素材、对话、全网热点或代码仓库动态，交给 AI 按你的文风画像起草文章，人工审阅后一键上传到微信公众号草稿箱。

它不是「一键发布机器」——所有产出默认进入草稿箱，等你审阅修改后再发表；敏感话题默认需要人工确认。

## 项目背景

作者日常运营公众号时，发现写作流程里最费时间的是三件事：把零散素材组织成文、每周找选题、把仓库的技术迭代讲成人话。这个工具把这三件事各自做成了独立的创作模式，共用同一套项目背景、文风画像与合规护栏（AI 内容标识、敏感话题闸、相似度自检），AI 只负责起草，发表权始终在你手里。

## 功能一览

- **四种创作模式**（见下文「四种创作模式」）
- **文风画像**：导入你的历史文章样文，AI 分析开头/收尾/句式/口头禅等习惯，成文时注入画像约束，另有 AI 味禁用词清单
- **项目背景**：填写系统简介、术语表、受众画像，所有创作模式共用，让 AI 用词与你的产品保持一致
- **合规护栏**：文末 AI 内容标识（默认开启）、敏感话题关键词闸（命中需人工确认）、n-gram 相似度自检（超阈值自动重写）、来源清单仅内部留档不随文发布
- **定时任务**：每天定点自动成文并上传草稿箱，支持仓库自动 / 内容池 / 选题雷达三种定时模式，错过的任务开机补跑
- **托盘驻留**：关闭窗口最小化到托盘，定时任务照常执行；结果走系统通知
- **密钥加密**：AppSecret / 大模型 Key / 搜索 Key 在 Windows 上经 DPAPI 加密落盘，配置导出自动脱敏

## 环境要求

- Node.js 22+
- npm（随 Node 安装）
- Windows 10/11 或 macOS（打包对应平台的安装包）
- 一个微信公众号（订阅号或服务号，需有「素材管理 / 草稿箱」接口权限）
- 一个大模型服务商的 API Key（如智谱 / DeepSeek，OpenAI 兼容接口均可）
- （选题雷达可选）一个搜索服务的 API Key，或使用智谱 / DeepSeek 自带的搜索接口复用大模型 Key

## 安装与配置

```bash
git clone https://github.com/sakura824/automatic-article-generation.git
cd automatic-article-generation
npm install
npm run app:mock   # 无任何密钥，先用 mock 模式体验完整界面与流程
```

mock 模式下微信接口与大模型都是确定性桩，不发起任何真实网络请求，可以先把四种模式都点一遍。体验完成后，进入正式配置（应用内「配置向导」会带你走一遍）：

1. **公众号凭证**：到公众平台「设置与开发 → 基本配置」获取 AppID 并重置 AppSecret，填入设置页；
2. **IP 白名单**：调用微信接口要求把本机公网 IP 加入白名单（设置页会显示本机 IP 并一键复制），否则会报 `40164` 错误；
3. **大模型**：填入 API Key 与模型名（预设智谱 bigmodel / DeepSeek，或填任意 OpenAI 兼容 Base URL）；
4. **搜索 Key（选题雷达需要）**：推荐博查（独立服务，与模型无关）；智谱 / DeepSeek 自带搜索接口时可复用同一家的大模型 Key；
5. 也可参考仓库里的 `config.example.json`（与程序默认配置同形、密钥全空），复制到系统用户数据目录根下的 `config.json` 后按需修改（Windows 为 `%APPDATA%\公众号写作助手\config.json`）。

## 四种创作模式

### 1. 素材成文（主力）

把聊天记录、读书笔记、链接摘要等零散素材粘贴进左侧素材区，写一句「今天想强调的点」，AI 提取事实与要点、按你的文风画像成文。原文句式与比喻不会被搬运——这是提示词里的硬约束。

### 2. 对话共创

从一个模糊的想法开始，AI 像写作搭档一样追问细节（受众？例子？数字？），聊清楚后点「把这轮讨论整理成文章」成稿。会话可保存、可续聊。

### 3. 选题雷达

配置若干关键词，每天自动搜索全网内容 → 白名单过滤 → 去重 → 按权威度与热度排序生成热点清单；勾选 1~3 条选题，AI 只提取来源中的事实、共识与数据综合成文（引用出处，不复用句式）。支持来源分级（L1 官方机构 / L2 学术 / L3 科普）与全自动定时成文。

### 4. 仓库自动（可选）

指定一个本地 git 仓库，每天收集新增提交生成 diff 摘要，AI 据此写一篇项目进展推文。适合把技术博客日常化；不开定时也可以手动触发「立即生成并上传」。

## 打包成桌面端

### Windows

```bash
npm run pack
```

产出在 `dist/`：NSIS 安装包（可选安装目录、创建桌面快捷方式）+ 免安装 portable exe 各一份。图标使用 `build/icon.ico`。

### macOS

mac 包必须在 **Mac 上**构建（Windows 无法构建 mac 包）：

```bash
npm install
npx electron-builder --mac
```

或 `npm run pack:mac`。产出 `dist/` 下的 dmg 与 zip。mac 打包需要 `build/icon.png`（仓库已内置 1024×1024 版本；如需重新生成，可在 Windows 上运行 `powershell scripts/make_app_icon.ps1 -OutIco build/icon.ico -OutPng1024 build/icon.png`）。

## 目录结构

```
├── main/            # Electron 主进程：窗口/托盘/IPC/调度宿主/文章落盘与上传
├── preload/         # 上下文隔离桥：渲染层只经 window.api 白名单通道通信
├── renderer/        # 渲染层：单页应用（八视图）+ 演示桥（无后端时展示示例数据）
├── src/core/        # 纯 Node 业务核心：config/collect/pipeline/chat/aggregate/style/…
├── test/            # node:test 单元与端到端测试（mock 桩，零真实网络）
├── scripts/         # 冒烟/校验/打包辅助脚本
├── assets/          # 应用内置封面等资源
├── build/           # 打包图标（icon.ico / icon.png）
├── docs/            # 文档与图片资源
├── electron-builder.yml
└── config.example.json
```

运行期数据（`config.json` / `state.json` / `logs` / `output` 等）都直接写在系统用户数据目录根下，不污染仓库；`config.json` 含密钥，已被 `.gitignore` 排除。

## 常见问题

- **报 `40164 invalid ip`**：本机公网 IP 不在公众号白名单里。到设置页复制本机 IP，到公众平台「基本配置 → IP 白名单」添加后重试；家宽 IP 变化后需重新添加。
- **AppSecret 报错（40001）**：Secret 重置后旧值立即失效，重新获取并保存。
- **测试连接通过但上传失败**：检查账号是否有草稿箱/素材管理接口权限；未认证订阅号部分接口受限。
- **生成内容质量一般**：把项目背景（简介/术语/受众）和文风画像先配好，再喂更完整的素材——这些输入比换模型影响更大。
- **选题雷达搜索失败**：检查搜索 Key 与对应服务商是否匹配；智谱/DeepSeek 自带搜索要求大模型也是同一家才能复用 Key。
- **敏感话题提示需人工确认**：这是有意的合规闸。敏感词列表默认留空，请在配置里按自己的领域配置（`aggregate.sensitiveKeywords`，如网络博彩、刷单返利、绝对化收益承诺等违规题材），或确认题材安全后再次点击成文。
- **想完全离线体验**：`npm run app:mock`，全程不发真实请求。

## 合规与免责

- 本工具生成的均为 AI 起草内容：默认在文末附加 AI 内容标识，发表前**必须人工审阅修改**，遵守《人工智能生成合成内容标识办法》与微信公众平台运营规范；
- 选题雷达只提取来源中的事实与共识并署名出处，不搬运原文；来源清单仅供内部核查，不随文发布；
- 领域提示、敏感词表均为可配置项：涉及医疗、金融等专业领域的公众号，请自行把控内容合规性并咨询专业人士；
